# Contributing Guide

Thank you for your interest in contributing.

This project primarily focuses on **documentation**. Contributions that improve clarity, accuracy, structure, and usefulness of the documentation are welcome.

## How to Contribute

1. **Fork** the repository.
2. Create a new branch for your changes.
3. Make your documentation changes.
4. Keep the content clear, concise, and easy to understand.
5. Check spelling, grammar, formatting, and links.
6. Commit your changes with a clear message.
7. Open a **Pull Request** with a short description of what you changed and why.

## Documentation Guidelines

* Keep information accurate and up to date.
* Use clear and simple language.
* Follow the existing Markdown structure and formatting.
* Avoid unnecessary or duplicated content.
* Use examples where they improve understanding.
* Do not include unrelated changes in a documentation PR.

## Pull Requests

Please make sure your Pull Request:

* Has a clear title and description.
* Contains only relevant changes.
* Has been checked for formatting or broken links.

All contributions are reviewed before being merged.
