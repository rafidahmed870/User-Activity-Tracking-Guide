# Code of Conduct

We are committed to maintaining a friendly, respectful, and inclusive community for everyone contributing to this project.

## Expected Behavior

Contributors are expected to:

* Be respectful, constructive, and professional.
* Give helpful and honest feedback.
* Respect different opinions, experience levels, and approaches.
* Keep discussions focused on improving the documentation and code examples.
* Provide clear explanations when suggesting changes or corrections.
* Make code examples readable, safe, and easy to understand.

## Unacceptable Behavior

The following behavior is not acceptable:

* Harassment, discrimination, insults, or personal attacks.
* Trolling, unnecessary arguments, or intentionally disruptive behavior.
* Sharing inappropriate, offensive, or harmful content.
* Deliberately submitting misleading or harmful documentation or code examples.
* Publishing private or sensitive information without permission.

## Code & Documentation Discussions

Technical disagreements are welcome, but discussions should remain respectful and focused on the problem rather than the person.

When reviewing documentation or code, focus on:

* Correctness
* Clarity
* Maintainability
* Security and safety
* Consistency with the project's documentation style

Different solutions may be valid. Contributors should explain their reasoning and remain open to discussion.

## Reporting Issues

If you experience or observe behavior that violates this Code of Conduct, please report it through the project's designated communication or issue-reporting channel.

Reports will be handled respectfully and, where possible, kept confidential.

## Enforcement

Contributors who violate this Code of Conduct may have their comments, issues, pull requests, or other contributions moderated or removed. Serious or repeated violations may result in being restricted or removed from the project community.

By participating in this project, you agree to follow this Code of Conduct.
